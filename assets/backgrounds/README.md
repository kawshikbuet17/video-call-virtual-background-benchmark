# Backgrounds

Images used for background replacement. Both are 1280x720 and were generated
by `make_backgrounds.py` (standard library only, no license restrictions).

| File | What it is |
|------|------------|
| `gradient_blue.png` | Blue-to-teal gradient |
| `simple_room.png` | Plain wall, floor and a window |

To use your own, copy a `.jpg` or `.png` into this folder. It is resized to
the frame size automatically.

To regenerate the images (run from this folder):

```
python make_backgrounds.py
```
